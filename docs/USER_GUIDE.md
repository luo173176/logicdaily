# 用户使用手册

这本手册假设你第一次打开 LogicDaily。全程约 3 分钟读完，之后每天只需要 5～15 分钟。

## 0. 你需要先知道的三件事

1. **数据在你这台设备上。** 不需要注册，不需要联网，你写的一切都存在浏览器里。详见 [隐私说明](PRIVACY.md)。
2. **AI 是可选的。** 没配置也能用全部功能。配置了才有教练追问。
3. **这里不给你打分。** 报告里的每个数字都有「怎么算」，样本不够时会直接写「样本不足」，不会告诉你「逻辑能力提升 20%」。

## 1. 第一次打开

装到手机主屏幕（推荐，之后离线可用）：

1. 用 Chrome 打开你的站点地址（需要 HTTPS）。
2. 菜单 → **添加到主屏幕**。
3. 从主屏幕图标进入，会以独立应用、竖屏方式打开。

电脑上直接访问即可。首次打开会看到「正在载入题库…」，几秒后 112 道题就存进本机了。之后即使断网也能正常训练。

如果一直卡在载入并提示本地存储不可用，多半是浏览器处于隐私/无痕模式——换一个普通窗口。首页底部有「重新载入题库」按钮，题库显示为空时可以点它。

## 2. 新手引导（30 秒，可跳过）

首页会问你是否第一次使用。引导只有三步：

- **每天能投入多少时间**（默认 10 分钟）：这决定每天生成多少题。
- **选择感兴趣的训练方向**：不选也行，系统会按你的表现自己调整。
- **休息日**：设为休息日的那几天任务会减轻，而且**不会中断连续天数**。

完成后自动进入训练页。这些设置随时可以在「我的」里改。

## 3. 每天怎么用

### 第 1 步：做一道题（约 2 分钟）

`训练` 页会给出今天的队列，顶部显示「第 N 题 · 预计 X 秒 · 新题/复习」。

1. 读题干。
2. 作答：单选点选项；多选勾选所有你认为成立的；判断题二选一；简答题写关键词即可（系统按检查点匹配）；排序题**按顺序点选项**，点错了可以再点取消；开放题写完自己的判断再自评。
3. **建议写「你的推理过程」**。这一步很重要：只有写出来，系统才能定位你是哪一类问题，教练也才能追问。
4. 选一个信心等级（1～5）。
5. 提交。

### 第 2 步：看解析，并回答「这次更像哪种情况」（约 1 分钟）

提交后你会看到：

- 结果：答对 / 未答对 / 部分正确 / 已按自评记录。
- 参考答案与你的答案。
- **解析**：结论、推理步骤、典型错误说明。
- **归因**：系统根据题目预设的错误类型 + 你的用时 + 你的信心，给出这次失误更像「推理方式需要调整」「相关知识不足」「匆忙作答」「读错题干」还是「题目本身有歧义」。
- 你可以补一个自述标签：`我粗心了 / 有不懂的术语 / 我读错题干了 / 题目本身有歧义`。
  - 这个标签**只改变归因统计，不会改你的得分，也不会改复习排期**。
  - 选了「题目本身有歧义」，这道题会进入题库复核清单（在「我的」页可以看到），这是你帮项目改进题库的方式。
- **下次复习时间**及原因，例如「明天再练一次：这是你第一次答错的题」。

不满意解析可以直接问教练（如果已启用）：面板会先反问你，而不是给你答案。

### 第 3 步：写一篇思考日志（约 5 分钟）

这是本应用真正的核心。前面做题只是热身。

`日志` → 右上角「新建」。

**快速记录**：只填标题和「问题」就够了，其他以后补。

**八步向导**（每步都可以跳过，不会丢结构）：

| 步骤         | 写什么                                               | 常见误区                 |
| ------------ | ---------------------------------------------------- | ------------------------ |
| 1 问题       | 一个具体、可判断的问题：「要不要把评审会提前到周一」 | 写成主题词：「关于评审」 |
| 2 背景       | 谁在意、有什么约束、时间压力                         | 长篇叙事，把结论混进来   |
| 3 事实与推测 | **分开写**。观察到的写左边，你猜的写右边             | 把推测当事实             |
| 4 假设       | 你的结论默认成立、但其实没验证的前提                 | 想不起来写，就空着       |
| 5 结论       | 你现在倾向于怎么判断                                 | 含糊其辞，不敢写         |
| 6 另一种解释 | 如果结论是错的，什么解释同样说得通                   | 只写「也有可能吧」       |
| 7 关键不确定 | 哪一条信息一旦变化，结论就翻                         | 列一堆无关紧要的         |
| 8 验证动作   | 一个小成本、能区分两种解释的动作                     | 写成「再想想」           |

**证据清单**：在编辑器下半部分可以添加证据。每条要写内容、标注立场（支持我的结论 / 与结论冲突 / 支持另一种解释 / 暂时不确定）、可靠性 1～5、来源。

> 建议刻意去加**与结论冲突**的证据。报告页会统计「主动记录反面证据的比例」——这是行为指标，不是成绩，但它比正确率更能预测你判断质量的改善。

**复盘到期**：给日志设一个到期日（例如两周后），到期它会自己出现在复习队列里，提醒你对比「当初的信心」和「实际结果」。

**状态**：仍在思考 → 待复盘 → 已复盘 → 已做决定 → 已归档。

**删除**：编辑器里可以先删除（软删除，列表和统计立刻消失），也可以彻底删除（不可恢复）。

日志默认**不会**发给任何模型。只有你在编辑器里勾选「允许把这篇送去 AI 分析」，它的内容才会被发送。

### 第 4 步：复习（约 2 分钟）

`复习` 页列出到期的题目和到期待复盘的日志。每项都写着**为什么排到今天**（逾期几天、上次答错还是答对、当前间隔）。

答错的题会进入「当日重学」：约 30 分钟后再问一次，而不是等到明天。

连续答错多次的题会被标记为「顽固错题」，间隔不再继续拉长。

### 第 5 步：看报告（可选，一周一次）

`我的` → 训练报告，或底部 `统计`。

- 顶部可切换时间范围：今天 / 本周 / 近 30 天 / 全部记录。
- 每个指标下面的「怎么算」展开就是它的精确口径，包括分母是什么、哪些记录被排除。
- 「知识点掌握度」要求单个知识点至少 3 次作答才计算。
- 「复习后表现变化」需要至少 6 组「同一道题首次 vs 复习」的配对样本，否则显示「样本不足」。
- 「建议」区域在数据不足时只会说「先积累数据」，不会硬给结论。
- 报告页固定有一段「这些数字不能说明什么」。

## 4. AI 思维教练（可选）

如果部署者配置了模型，你会在答题解析下方和日志编辑器里看到教练面板。

它能做：

- **追问**：指出你推理里缺的那一步，用问题形式让你自己补上。
- **拆论证**：把一段话拆成前提 / 结论 / 假设 / 证据 / 反例。
- **找最强反驳**：给出反对当前结论的最有力说法。
- **验证动作**：建议一个能区分两种解释的小实验。
- **材料分析**：`教练` 页可以粘贴一段外部文字（文章、方案、公告），让它分析结论、隐含假设、谬误与证据质量。
- **练习推荐**：根据你的薄弱点从题库里挑题。

你需要知道的限制：

- 它**默认不替你下结论**，只提问。想要直接答案，就在追问里明确说「请给我示范」。
- 它的回复里会有一个「不确定」字段，那是它自述的可靠性限制。**它并不总是正确**，尤其是事实性内容。
- 它不影响判分。你的得分完全由本地规则计算。
- 未配置时面板显示「AI 教练未启用」，其余一切照常。
- 有每日调用次数限制，用完会提示明天再来。

## 5. 提醒

`我的` → 提醒：

- 设定每天提醒时间、免打扰时段（支持跨午夜，如 22:30–07:30）、每周复盘日。
- 可以暂停提醒。
- 同一天只提醒一次；休息日不打扰；超过设定时间 2 小时不再打扰。

**必须如实告诉你**：作为网页应用，LogicDaily 无法保证在后台被准时唤醒。提醒只在应用被打开时生效。系统通知需要你在浏览器里授权，且不同浏览器行为不一致。**没有**服务端推送，所以关闭浏览器后不会有提醒。如果需要可靠的后台提醒，请用系统日历或闹钟。

## 6. 数据备份与迁移

`我的` → 数据管理：

- **导出备份**：下载一个 JSON 文件，包含你的作答记录、日志、复习状态、掌握度、计划与进度（不含题库本身）。
- **导入备份**：选择文件恢复。导入前会校验是不是本应用产生的、结构是否合法、版本是否支持；不合法会明确拒绝并说明原因。同一项数据以更新时间较新的一方为准，重复项跳过。
- **清除本地数据**：删除本机保存的设置、作答记录、复习队列、日志与分析结果，会要求确认。**不可撤销**，请先导出备份。已导出的备份文件不受影响。清除后页面会重新载入题库。

**备份文件是明文，包含你的思考日志。** 请像对待日记本一样对待它：不要放在公开网盘，不要提交到代码仓库，不要发给别人。

换设备：旧设备导出 → 新设备导入。

## 7. 常见问题

**题库显示为空 / 一直「正在载入题库」**
点首页的「重新载入题库」。若无效，检查是否处于无痕模式（隐私模式会禁用 IndexedDB）。

**为什么今天只有 2 项任务，昨天有 5 项**
任务量受「每日时长」预算、休息日、以及到期复习数量影响。到期复习多时，新题会自动减少。

**我答对了，为什么掌握度还是低**
掌握度按知识点算，不是按题目算。同一知识点在不同题型上答错会拉低它；单个知识点至少 3 次作答才开始计算。

**排序题我怎么知道顺序对不对**
按你认为的先后顺序依次点击选项，选中顺序会显示编号。再点一次可取消。提交后系统按「顺序一致性」给分，不要求全对。

**开放题算对吗**
开放题走自评量表，不计入正确率与平均得分（避免自己给自己打分污染统计），会计入作答量与复习调度。

**为什么有的题解析说「可接受其他答案」**
有些题确实存在两种合理读法。这类题在 `alternatives` 里写明了可接受的其他答案与理由，选到它同样给分。

**我觉得某道题出错了**
答完那题后点「题目本身有歧义」。它会进入题库复核清单，维护者能看到。

**能换主题/字体大小吗**
`我的` → 外观：跟随系统 / 浅色 / 深色。字体大小跟随浏览器设置（建议 100%～125%）。

**手机键盘挡住了输入框**
已针对小屏做了避让处理。如果仍被遮挡，请把浏览器缩放调小，或反馈机型与浏览器版本。

**数据会同步到云端吗**
不会。当前版本没有账户与云同步。要跨设备，请用导出/导入。

## 8. 每天 5 分钟的最低方案

只做一件事：**写一篇日志的问题 + 结论两步**。

理由：做题是练习，写下来才是你的真实判断。系统会等你补齐其他步骤，不会因为你没写完而惩罚你（完成度只是显示，不影响任何统计口径）。
